STEP BY STEP

Integrer på fire trinn

1

Registrer appen din

Åpne konsollen og opprett ett prosjekt per miljø. Prosjektet er eieren av nøkler, moduler og Credits.

2

Aktiver moduler

Velg Game Library, deretter hvilke spill appen skal ha tilgang til. Premium-moduler krever aktivt abonnement.

3

Opprett API-nøkkel

API-nøkler lagres kun på serveren din. Ikke legg dem i React Native, nettleseren eller offentlige repositorier.

4

Kall API-et fra backend

Send Authorization-header fra en betrodd server og håndter statuskoder, begrensninger og idempotens.

curl https://vedoy-dev-portal.vercel.app/api/v1/rewards/games

Spillkatalogen viser metadata. Spillmotorene er ennå ikke migrert til Rewards Core.

32 STANDALONE ENDPOINTS

Verktøy uten eksterne tjenester

Datavask, validering, CSV/JSON, koding, UUID-er, testdata, geografiske beregninger og datoer. Krever ingen database, API-nøkkel eller leverandørkonto.

Katalog med eksempeldata ↗ · OpenAPI for verktøyene ↗

curl -X POST /api/v1/tools/text/slug \
  -H 'Content-Type: application/json' \
  -d '{"text":"Blåbær og øyer"}'

Send JSON med maksimalt 64 KiB. Svarformat: {"data": ...}. Validering av adressefelt, telefon og bedriftsnummer bekrefter format eller kontrollsiffer; den utfører ikke registeroppslag. Ukedager utelukker ikke helligdager. Avstander er luftlinje.

PRODUCT GUIDE

Rewards & Highscore

Game Library lar deg registrere spillvalg på appen. Highscore API er en separat premium-beta for serverinnsendte resultater.

GET/api/v1/rewards/gamesOffentlig katalog
GET/api/v1/rewards/highscores?game=snakePremium · API-nøkkel
POST/api/v1/rewards/highscoresPremium · server-side

Highscores er foreløpig ikke verifiserte spillprestasjoner. Ingen Vedoy Coins tildeles.

BEST PRACTICES

Trygg integrasjon

Bruk Supabase-brukersesjon for kontrollpanelet, men prosjektets hemmelige API-nøkkel for server-til-server-kall. Bruk aldri en mobilapp som betrodd server. Alle premium- og modultilganger må håndheves på backend.

For operasjoner som endrer penger, poeng eller eksterne ressurser: bruk verifisering, idempotens, revisjonsspor og eksplisitte tillatelser.

BILLING

Abonnement og Vedøy Credits

Abonnement styrer hvilke premium-moduler et prosjekt har tilgang til. Credits er separat betaling for forbruk der dette er aktivert. Dokumentasjon er gratis.

Automatisk kjøp og administrasjon av abonnement er ennå ikke aktivert. Kontakt Vedøy Studio for tilgang.
